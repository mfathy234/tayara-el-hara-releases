## Install on your phone

1. On your Android phone, open the **Download the latest APK** link above.
2. Open the downloaded `TayaraElHara.apk`. If Android asks, allow your browser to install apps.
3. Play. New versions install over the old one and keep your saves. The game also tells you when an update is out.

This repository only holds the release downloads. The game's source code is private.
