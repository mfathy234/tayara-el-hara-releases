How to install

It takes about a minute. You only need an Android phone running 7.0 or newer.

  1. Download the APK

    On your Android phone, tap the Download APK button. If your browser warns that this type of file can be harmful, choose Download anyway. It is a test build outside the Play Store.

  2. Allow your browser to install apps

    Open TayaraElHara.apk from the download notification or your Downloads folder. If Android asks, switch on Allow from this source for your browser (Settings, Apps, Install unknown apps), then go back and tap Install.

  3. Play

    Open Tayara El Hara and pick a save slot. If Play Protect asks, tap More details, then Install anyway.

Your saves stay on the phone

Progress is stored on the device in three slots. There is no account and nothing is uploaded.

Updates install over the old one

Download the new APK and install it. Your saves are kept.

The game checks for updates

When a new version is out, the main menu shows an Update available button and What's new after you update.
